# shapelib

shapelib 1.6.3, by Frank Warmerdam and Even Rouault, which reads and writes
ESRI shapefiles. These files are copied unmodified from the release archive
`shapelib-1.6.3.tar.gz`
(https://github.com/OSGeo/shapelib/releases/tag/v1.6.3, SHA-256
3ff5ead18ca6d2fe249f0e80b361e1ad6782165115268ed4a58c780a60c1e0eb). shapelib
is available under the MIT license, in `LICENSE-MIT`, or the LGPL;
triangle-utils uses it under the MIT license. Replace the files together,
from a later release, to update it.
